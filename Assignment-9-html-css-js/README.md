## 📖 About

**Emerge** is a productivity web application designed to keep everything needed for a productive day in one place.

Instead of switching between multiple apps for notes, planning, timers, goals, and motivation, Emerge combines them into a clean, responsive dashboard with a modern UI and multiple customizable themes.

The project was built using **Vanilla HTML, CSS and JavaScript** without any external frameworks.

# 💾 Data Persistence

The application stores user data using **Local Storage**, allowing information to remain available even after refreshing or reopening the browser.

Stored data includes:

- Tasks
- Goals
- Daily Planner
- Notes
- Quotes
- Username
- Selected Theme
- Pomodoro Settings
